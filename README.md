# Art & Energy

Website for **art & energy**, a private Reiki studio with Giovanna Ferrari. Sessions combine Usui Reiki with optional intuitive drawing.

Studio working files (brand, copy, session notes) live in [`documents/art&energy`](documents/art&energy).

## Run locally

```bash
npm install
npm run dev
```

Open [http://127.0.0.1:43147](http://127.0.0.1:43147).

## Pages

- `/` — studio home

Session enquiries go through the contact form on the home page (session dropdown included) and are meant for `giovanna.ferrari.art@gmail.com`.

## Stack

Next.js, TypeScript, Tailwind CSS, and shadcn/ui.
